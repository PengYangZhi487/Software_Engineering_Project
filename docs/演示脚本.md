# RATGP 答辩演示脚本（5–8 分钟）

## 一、演示前 10 分钟准备

```powershell
# 一键启动（默认 dev 模式，和 npm run dev 一样，不需要先 build）
cd Software_Engineering_Project
.\tools\demo.ps1

# 想恢复固定演示数据（会清空所有项目，答辩推荐）
.\tools\demo.ps1 -Reset

# 想要更快的启动 / 生产模式（缺构建时会自动 next build）
.\tools\demo.ps1 -Prod
```

检查清单：

1. 浏览器打开 http://127.0.0.1:3000，页面不报「后端没有连上」；
2. 右上角钥匙图标：填入自己的 DeepSeek Key（只存在当前标签页，关掉即失效）；
3. 接口文档能开：http://127.0.0.1:8000/docs；
4. 报告页能下载 Excel（不耗额度，可提前演示一遍）。

> seed 重建后的基准：1 个项目 · 2 个文档版本 · 25 条需求（14 已确认 / 11 未审核）·
> 12 条用例（7 已审核 / 4 已生成 / 1 已驳回）· 10 条质量问题（6 模糊 + 4 冲突）· 覆盖率 43%。

## 二、讲稿与操作

### 1. 定位（30 秒）

「这个平台把需求文档变成可追踪、可复算的测试资产。AI 只负责加速录入，人工负责决策和交付。」

→ 停在**总览**页：25 条需求、10 个质量问题、43% 覆盖，一眼看到项目状态。

### 2. 需求抽取与人工确认（90 秒）

→ 文档工作台：展示段落解析、来源定位（¶ 编号 + 相似度）；
→ 点「抽取需求」：讲「默认是**追加抽取**，覆盖要显式选，不会误删已有需求」；
→ 需求库：筛选「未确认」，勾选 3 条 → 批量确认。

讲：编号由程序生成，不采信模型自己编的编号；确认/驳回都留痕。

### 3. 质量扫描与裁决（60 秒）

→ 质量页：模糊 / 冲突 / 缺验收三类；
→ 任选一条问题，点「确认」或「忽略」。

讲：规则可复现，同一份数据每次扫描结果一致；裁决按内容指纹保存。

### 4. 用例生成与审核（60 秒）

→ 用例页：点「生成用例」，勾选几条已确认需求 → 生成正常/异常/边界候选；
→ 勾选 2 条用例 → **批量通过**；
→ 讲「生成 ≠ 审核 ≠ 通过」：AI 只提候选。

### 5. 执行记录（60 秒，本轮新增）

→ 任选一条用例，点「记录执行」：
  - 执行结果：失败；
  - 实际结果：写一句真实现象；
  - 测试 comments：写备注；
  - 执行人 + 测试者签名；
→ 保存后用例卡出现「最近执行：失败」标记，顶部「执行记录」计数 +1。

讲：执行是真实动作，和生成、审核分开记；这也是导出 Excel 里「实际结果 / comments / 签名」的来源。

### 6. 追踪与变更（60 秒）

→ 追踪页：需求 × 用例矩阵、覆盖率口径（至少一条已审核用例的已确认需求 / 已确认需求总数）；
→ 变更页：V1.0 → V1.1 两处数字变化，列出受影响的需求和用例。

### 7. 报告与导出（60 秒）

→ 报告页：点「下载 Excel」；
→ 打开 xlsx，四个 Sheet：
  1. 概览；
  2. 需求清单；
  3. **测试用例执行表**（用例、步骤、预期、实际结果、comments、执行人、签名、执行环境、执行时间）；
  4. 覆盖矩阵。

讲：页面和文件同一份数据（同一个 `_build()`），数字可复算；CSV 仍保留。

### 7.5 导入导出闭环（60 秒，可选）

→ 需求库点「导出」，打开 xlsx，把某条需求标题改掉、再追加一行；
→ 回到需求库点「导入」，上传改过的文件，展示「更新 1 条 / 新增 1 条」；
→ 讲：Excel 当编辑器，软件负责编号、状态和追溯——不是替代 Excel，而是补上 Excel 管不了的部分。

### 8. 全局搜索（30 秒）

→ 顶部搜索框输入「容量」回车：需求、用例、质量问题三组结果一次出来。

### 9. 工程收尾（30 秒，可选）

→ 37 条后端测试、A3 事务修复、BYOK 安全（Key 不落盘）、静态导出/桌面封装规划。

## 三、收尾

- 关闭 `demo.ps1` 打开的**两个**控制台窗口（后端 + 前端）即停止；
- 恢复演示数据：`.\tools\demo.ps1 -Reset`。

## 四、兜底

| 问题 | 处理 |
|---|---|
| 端口被占 | `Get-NetTCPConnection -LocalPort 3000` 找到 pid 后 `Stop-Process -Id <pid>` |
| 后端起不来 | 看 uvicorn 窗口；数据库在 `App\data\ratgp.db`，备份是 `ratgp.db.bak-*` |
| 没有 Key | 抽取/生成会 401；先演示已有数据、质量扫描、追踪、报告导出（都不耗额度） |
| Excel 打不开 | 确认 openpyxl 已装：`.\venv\Scripts\python.exe -c "import openpyxl"` |
| 页面样式错乱 | 确认 `npm run dev` 窗口没有报错；生产模式重新 `npm run build` |
