## 这一版有什么

| 视图 | 关键点 |

**4 个空状态视图**（质量 / 用例 / 变更 / 报告）—— 这一版只演示空状态该长什么样：一句说明 + 一个主操作，而不是 `⏳ 待实现`。

## 主题（P0.1 新增）

右上角按钮 → 三选一，选择写进 `localStorage`，刷新保留；也可以用 URL 强制：

| 主题 | 观感 | 用途 |
|---|---|---|
| 浅色 | 中性灰白 + 靛蓝强调 | 默认，投屏答辩最清楚 |
| 玻璃淡紫 | 薰衣草底 + 磨砂玻璃面板 | 演示、截图，辨识度最高 |
| 深色 | 近黑底 + 亮紫强调 | 长时间盯屏 |

`preview.html?theme=glass`、`preview.html?theme=dark`。

实现上只有一套语义变量（`bg / surface / line / text / accent / ok / warn / danger`），主题只换变量值，组件 CSS 一行不用改。玻璃主题额外做三件事：

1. 页面底部铺一层低饱和光晕 —— 否则 `backdrop-filter` 没有东西可透，玻璃就退化成"白色卡片"；
2. 面板 `rgba(255,255,255,.40)` + `blur(26px) saturate(185%)` + 1px 白色描边 + 顶部内高光；
3. 菜单、抽屉这类"必须读字"的浮层不给透明度，可读性优先。

代价也说清楚：玻璃主题的对比度天然低于浅色主题，长时间读表格不如浅色舒服。所以**默认仍是浅色**，玻璃是"可以切过去的第二种皮肤"，不是唯一答案。

## 数据说明

- **真实的**：25 条需求（CR-001～CR-025）、52 个文档段落、段落定位（`¶` 编号与相似度）、6 条模糊（CR-015～CR-020）、5 组冲突（CR-021～CR-025）——全部来自 `App/data/ratgp.db` 与 `test_file/datasets/course_selection_v1.docx`。
- **示例的**：13 条用例、60% 覆盖率、最近活动时间线。因为 `case_service` / `track_service` 还没实现（M4–M7），这部分是目标态演示，页面上有「设计预览」标记，不要当成已有功能。

## 设计决策

| 原来（Streamlit） | 现在 | 为什么 |
|---|---|---|
| 蓝色渐变侧栏 + 彩色卡片 + 大投影 | 中性灰底 + 白面板 + 1px 描边，阴影只给抽屉 | 高端 = 克制。一个投影层级就够 |
| 标题挂满 emoji | 一个 emoji 都没有，用线性图标 / 纯文字 | emoji 是最容易暴露「课程作业感」的东西 |
| 5 个并列菜单 | 一条主线：文档 → 需求 → 质量 → 用例 → 追踪 → 变更 → 报告，带状态点 | 评审看的是流程闭环（G1），不是菜单数量 |
| 4 块大色 metric | 一条指标条，数字 + 单位 + 副标注 | 信息密度上去了才像工具，不像 demo |
| `st.dataframe` | 行高 41、等宽编号、状态用 6px 圆点 | 表格是这类产品的主战场 |
| 「⏳ 待实现」 | 空状态：说明 + 下一步按钮 | 没做完也要有一个好看的「没做完」 |
| 一切靠页面跳转 | 抽屉、联动高亮、筛选即时生效 | 局部反馈是「产品感」的主要来源 |

配色只有一个强调色（`#4F46E5`），语义色只用于状态；圆角 12/9/6 三档；间距走 4 的倍数；动效 140/220ms，只动 `opacity` 和 `transform`。

## P1 落地约定（待确认）

- **栈**：Next.js 15（App Router）+ TypeScript + Tailwind + shadcn/ui + TanStack Query / Table + Recharts + Framer Motion
- **主题**：`next-themes` + 同一套 CSS 变量，`data-theme` 挂在 `<html>`；玻璃主题的 `backdrop-filter` 在低端机降级为纯色（`@supports not (backdrop-filter: blur(1px))`）
- **结构**：`web/app/(workspace)/[step]/page.tsx` + `web/components/`（AppShell、PipelineNav、MetricStrip、ReqTable、ReqDrawer、MatrixGrid、CoverageRing、EmptyState、ThemeMenu）
- **数据**：P1 先用 `web/mocks/*.json`（与预览页同结构）跑通界面；P2 再接 FastAPI + SQLite，`App/dao`、`App/services` 原样复用
- **验收**：P1 结束时 `/overview`、`/requirements` 两个路由可跑、三套主题可切、抽屉可用；截图与 `shots/` 一致
